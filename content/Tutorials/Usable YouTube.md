Requires [[Firefox is the best browser|Firefox]] on a desktop environment.
## 🪦 YouTube is getting worse.
YouTube has made some terrible choices— removing annotations, user contributed subtitles (an accessibility feature), in video polls, more than 4 community poll options, made search results worse and so much more...

Has YouTube improved at all in the past few years? For me, it has. I started using more and more extensions to make my experience so much better.
## 🔧 How to make it better:

| Addon                                                                                                            | Description                                                                                                                                                                         |
| ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [Auto Tab Discard](https://webextension.org/listing/tab-discard.html)                                            | Stop loading YouTube tabs in the background.                                                                                                                                        |
| [BlockTube](https://github.com/amitbl/blocktube)                                                                 | Block specific channels and videos, block by keyword and runtime, block auto-generated playlists                                                                                    |
| [Enhancer for YouTube](https://www.mrfdev.com/enhancer-for-youtube)                                              | I only use this for screenshots                                                                                                                                                     |
| [Multiselect for YouTube](https://ms4yt.com/)                                                                    | Useful for making and managing playlists— however I do not make playlists as a rule because of rotten links being silently removed without any indication of what was there before. |
| [PocketTube: YouTube Subscription Manager](https://pockettube.io/)                                               | I don't use notifications because I can see every new upload, sorted by genre.                                                                                                      |
| [Return YouTube Dislike](http://returnyoutubedislike.com/)                                                       | The only people who use this like to hate things. It's not very encouraging.                                                                                                        |
| [Theater Mode for YouTube (large player view)](https://webextension.org/listing/youtube-tools.html?from=theater) | Without suggestions, I'd like the video to take up more space.                                                                                                                      |
| [uBlock Origin](https://github.com/gorhill/uBlock#ublock-origin)                                                 | Ad block.                                                                                                                                                                           |
| [Unhook - Remove YouTube Recommended & Shorts](https://unhook.app/)                                              | Disabling recommendations makes YouTube better.                                                                                                                                     |
| [YouTube Anti Translate](https://github.com/artisticfox8/yt-anti-translate)                                      | YouTube thinks people want titles and descriptions to be translated to your default language. No, it's just confusing when you're multilingual.                                     |
| [YouTube No Translation](https://youtube-no-translation.vercel.app/)                                             | Not sure which one of these is functional.                                                                                                                                          |
| [YouTube Search Fixer](https://phoennix.gitlab.io/youtubesearchfix/)                                             | Give relevant search results for once.                                                                                                                                              |
| [YouTube Shorts Redirect](https://github.com/huantianad/youtube-shorts-redirect)                                 | I need to watch Game Changer Shorts.                                                                                                                                                |
## 🫖 Postscript
YouTube mobile is still a problem. I usually use a client, but few are updated for IOS.

There is a "do not suggest this channel" and "remove recommendation" options to prune suggestions, I might write an addon to make those available for all videos.
